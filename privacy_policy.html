Privacy Policy for VI Teacher Toolkit

Last Updated: June 3, 2026

This privacy policy governs your use of the software application VI Teacher Toolkit ("Application") for mobile devices. The Application is designed as a productivity utility for teachers to manage timetables, student profiles, attendance, passwords, and reminders.

1. Data Collection and Usage

No Personal Information Collection: The Application does not collect, transmit, or share any personally identifiable information (PII) or user data. All information you input into the Application is stored securely and locally on your device.

This includes:

  • Student names, profiles, roll numbers, and parent details.
  • Timetable entries and school hours.
  • Saved passwords/credentials (which are encrypted using Android's Keystore system before saving).
  • Attendance logs and historical records.

2. Third-Party Services and Transmission

The Application runs entirely client-side. It does not send any data to external servers, database hosts, or third-party analytical companies. Your data remains strictly on your device.

3. Local Storage and Encryption

All application database files are stored locally in the App's secure private directory. Passwords and sensitive configurations are encrypted using standard security libraries before writing to storage.

4. Backup Data

If you choose to create a database backup using the built-in backup utility, the backup file is written to your local device's folder (e.g., the Downloads directory). The Application does not upload your backup files to any cloud or remote servers. You are solely responsible for the safety and distribution of your backup files.

5. Permissions Used

  • VIBRATE: Used to provide haptic feedback for button presses.
  • INTERNET: Not utilized for data collection or tracking.
  • CALL_PHONE: Used strictly to let you initiate calls to parents/guardians from student profiles directly via your device's default dialer.
  • SCHEDULE_EXACT_ALARM & RECEIVE_BOOT_COMPLETED: Used to trigger alarms and notifications for timetable period alerts.

6. Changes to This Privacy Policy

We may update our Privacy Policy from time to time. We will notify you of any changes by posting the new Privacy Policy on this page.

7. Contact Us

If you have any questions regarding privacy while using the Application, please contact the developer via GitHub.
